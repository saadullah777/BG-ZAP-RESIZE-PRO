# ⚡ BG-Zap & RESIZE PRO

A professional, fast, and 100% mobile-responsive web application powered by AI to instantly remove image backgrounds and apply custom resizing simultaneously. Perfect for passport/ID photos, e-commerce sellers, and social media content creators.

## ✨ Features

* **🤖 AI Background Removal:** Powered by the `rembg` engine to intelligently detect foreground subjects and erase backgrounds instantly.
* **🎨 Smart Backdrop Switcher:** * *Transparent (PNG)* for graphic design work.
    * *Solid Color (Passport/ID)* with an interactive color picker.
    * *Custom Background Image* to upload and swap new backdrops seamlessly.
* **📐 Pixel-Perfect Resizer:** Custom width and height adjustments using high-quality anti-aliasing scaling (`LANCZOS`).
* **🔄 Quick Transforms:** Instant image rotation adjustments (90°, 180°, 270°, 360°).
* **📱 Mobile-First Layout:** Responsive user interface designed to scale beautifully on both smartphones and desktops.
* **🎈 Instant One-Click Download:** Clean download button saves processed files straight to your device gallery or storage.
